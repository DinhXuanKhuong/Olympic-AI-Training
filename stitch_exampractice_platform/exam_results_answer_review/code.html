Consider standard pointer-based array implementations without external cache optimization assumptions.

lightbulb Explanation & Mathematical Derivation

Bubble Sort, Insertion Sort, and Selection Sort possess quadratic average time complexity of O(n²). In contrast, Merge Sort divides the array recursively into halves (log n depth) and merges sub-arrays in linear O(n) time, yielding guaranteed O(n log n) performance across best, average, and worst-case scenarios.

Which data structure is typically utilized to implement Breadth-First Search (BFS) over an unweighted graph?

Assuming standard level-order discovery order from an initial source vertex.

A Stack (LIFO)
B Queue (FIFO)
done_all Your Selection • Correct
C Priority Queue (Min-Heap)
D Binary Search Tree
check_circle Resolution Analysis

Breadth-First Search inspects vertices in increasing order of their shortest-path distance from the source. A Queue (FIFO) guarantees that child nodes discovered at depth d+1 are placed behind all remaining unvisited nodes at depth d. Contrast with Stacks which yield Depth-First Search (DFS).
